# Forge Platform roadmap

| Stage | Scope |
| --- | --- |
| 0 | Repository foundation |
| 1 | Artifact, component-manifest, and compatibility contracts |
| 2 | macOS native installer |
| 3 | Clean local complete-platform install |
| 4 | Updater, repair, and uninstall |
| 5 | Windows/Linux agent and client installer support |
| 6 | Distributed and team deployment |

Stages are sequencing guidance, not commitments to implementation details or release dates.
