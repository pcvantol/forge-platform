# Forge Platform development extension

This local extension governs only Forge Platform-specific development semantics:

- distribution and deployment architecture;
- compatibility validation and release composition;
- artifact integrity verification;
- installer qualification;
- signing and notarization testing; and
- platform-specific release validation.

It does not define generic branch, worktree, handoff, repository-governance, or TDE contracts. Those are supplied by the future generated central projection.
